# F10AI — AI-powered tools for CorelDRAW

F10AI is a commercial, closed-source plugin for CorelDRAW on Windows. It brings AI image creation and editing, local font management, image processing, batch utilities, layout and prepress workflows into a single toolbox.

**This repository showcases the product and its documentation. Core source code is not publicly distributed.**
