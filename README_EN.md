# F10AI — AI-powered tools for CorelDRAW

F10AI is a closed-source plugin for CorelDRAW on Windows. It brings AI image creation and editing, local font management, image processing, batch utilities, layout and prepress workflows into a single toolbox.

**This repository showcases the product and its documentation. Core source code is not publicly distributed.**

[中文介绍](README.md) · [Installation](docs/installation.md) · [Features](docs/features.md) · [Issues](../../issues)

## Technology

F10AI integrates with CorelDRAW on Windows and uses **C# / .NET** for plugin logic and application interaction, **HTML / CSS / JavaScript** and **WebView2** for user interfaces, **Node.js** for online services, and **Python / PyTorch** for selected local AI features. This is a high-level technology overview; implementation details remain private.

**Compatibility:** CorelDRAW X8–2026 (features and dependencies may vary by released version). Some images show earlier builds.
