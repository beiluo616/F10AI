# F10AI 功能介绍

F10AI 面向 CorelDRAW 日常设计、广告制作和印前处理工作。功能可能随版本更新，部分功能仍在持续开发。

## AI 图像创作
- **AI 任务台**：统一管理图像生成及编辑任务。
- **区域重绘**：圈定需要修改的局部区域，进行去除、替换、增补及其他编辑。

## 字体与文字
- **字体管理**：浏览、预览、筛选本机字体。
- **转曲还原**：探索将转曲文字恢复为可编辑文本的工作流；实际能力以正式版本为准。
- **原位识别、文字校对及文本替换**：辅助文字提取、纠错和批量编辑。

## 图片与图形
- 智能抠图、图转矢量、巡边和高清处理。
- 颜色替换、选取相同、二维码生成。

## 排版、印前与效率
- 数码拼版、一键拼版、分页、拆分、添加页码。
- 批量导入、批量导图、节点处理、智能群组及 CDR Agent。
